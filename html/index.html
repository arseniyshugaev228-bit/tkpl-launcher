а полвечера ставил Forge.

  • Ищешь установщик под нужную версию и не знаешь, какой из пяти правильный. TKPL сам показывает загрузчики, которые реально есть для твоей версии.

TKPL берёт это на себя.

Вопросы

Что обычно спрашивают

Windows пишет, что файл может быть опасен. Это нормально?

Да. Так Windows реагирует на любую программу без платной цифровой подписи, особенно новую. Нажми «Подробнее» → «Выполнить в любом случае».

Нужно ли отдельно ставить Java?

Нет. Нужную версию Java лаунчер скачивает сам вместе с игрой.

Куда устанавливается игра?

В папку %USERPROFILE%\.tkpl_minecraft. Сборки лежат там же, каждая в своей подпапке.

Нужна ли лицензия Minecraft?

Да, для игры нужна купленная Minecraft: Java Edition. Лаунчер ничего не взламывает: игра, Java и библиотеки скачиваются с официальных серверов Mojang, а Forge, NeoForge и Fabric — с их официальных сайтов. Играя, ты принимаешь лицензионное соглашение Minecraft (EULA). Купить Minecraft.

Можно выложить лаунчер у себя или переделать?

Делиться можно только оригинальным файлом и со ссылкой на этот сайт. Продавать лаунчер, выкладывать изменённые версии, декомпилировать и выдавать за свою работу нельзя без разрешения автора. Подробно — в лицензии TKPL Launcher.

Сколько стоит?

Нисколько. Лаунчер бесплатный и без рекламы.
